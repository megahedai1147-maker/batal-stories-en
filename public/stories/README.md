# مجلد صور أغلفة القصص

## طريقة إضافة الصور

ضع صورة كل قصة في هذا المجلد باسم:
  story-{رقم القصة}.png

## أمثلة:
  story-1.png   ← الصدق ينجي
  story-2.png   ← شجاعة المختلف
  story-3.png   ← المشاركة تضاعف الفرح
  ...
  story-60.png  ← أميرة القصص

## المواصفات المثالية:
  - الحجم: 400 × 520 بكسل (أو أي نسبة 3:4 تقريباً)
  - الجودة: PNG أو JPG عالي الجودة
  - الحجم: أقل من 500KB للصورة

## بعد إضافة الصورة:
  افتح components/Catalog.tsx
  ابحث عن: const hasImage = false
  غيّرها لـ:  const hasImage = true
  (أو اعمل array بأرقام القصص اللي عندها صور)

## إذا ما في صورة:
  الموقع يعرض تلقائياً الـ placeholder الملون الجميل
  مع شارة "🖼️ صورة قريباً"
